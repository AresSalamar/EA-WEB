# Astara Retail Perú Showroom & Vehicle Inventory Management

## Description
This is a Single Page Application (SPA) developed for Astara Retail Perú. It provides a structured digital platform to efficiently manage the capacity of their exhibition rooms (showrooms), view vehicle stock lots by category, and assign vehicle models to specific inventory sections within the dealership. The project is built following Domain-Driven Design (DDD) principles, applying a layered and component-based architecture.

## Stack
*   **Language:** JavaScript
*   **Frontend Framework:** Vue 3 (Composition API)
*   **State Management:** Pinia
*   **Routing:** Vue Router
*   **Internationalization:** Vue I18n
*   **UI Components:** PrimeVue (with PrimeFlex and PrimeIcons)
*   **HTTP Client:** Axios
*   **Mock Backend:** JSON Server (Fake API)
